# The Margins Bookshop Events

A lightweight independent bookstore events page built with semantic HTML5 and vanilla CSS.

## Run locally

Open `index.html` in a modern browser, or serve the folder with any static web server. No build step, JavaScript, or dependencies are required.

## Included behavior

- Responsive event cards with accessible search and filter controls
- Accessible request form with native browser validation
- Semantic markup and keyboard-friendly links and controls
